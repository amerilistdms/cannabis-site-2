# Cannabis Email Lists — Site 2

Alternate visual treatment of the Cannabis Email Lists marketing site.

Built from the original AmeriList cannabis site as a base, with a new color system, typography, navigation, buttons, and card styling so it reads as a distinct site while keeping the same pages and content structure.

## Local

```bash
npm install
npm run dev
```

## Stack

Next.js, TypeScript, Tailwind CSS, GSAP
